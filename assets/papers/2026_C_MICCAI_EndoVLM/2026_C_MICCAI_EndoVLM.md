# EndoVLM: An Endoscopy Vision-Language Pre-training Model via Anatomy-Guided Sparsity and Progressive Alignment

**Venue:** MICCAI 2026 | **Type:** Conference

**Authors:** Zhenyu Yi, Jianwei Xu, Yue Hu, Zhongwei Qiu, Sijing Li, Liang Huang, Bin Lv, Ling Zhang, Yingda Xia.

## Summary

A vision-language pre-training model for endoscopy that leverages anatomy-guided sparsity and progressive alignment to bridge visual and textual modalities in clinical endoscopic analysis.
