# Weakly-supervised Pre-training for 3D Human Pose Estimation via Perspective Knowledge

**Venue:** Pattern Recognition | **Type:** Journal

**Authors:** Zhongwei Qiu, Kai Qiu, Jianlong Fu, Dongmei Fu.

## Summary

Leverages perspective geometry knowledge for weakly-supervised pre-training, significantly reducing annotation requirements for 3D human pose estimation.
