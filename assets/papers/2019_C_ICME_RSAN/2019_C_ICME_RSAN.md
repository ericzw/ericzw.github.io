# Learning Recurrent Structure-guided Attention Network for Multi-person Pose Estimation

**Venue:** ICME 2019 (Oral) | **Type:** Conference

**Authors:** Zhongwei Qiu, Kai Qiu, Jianlong Fu, Dongmei Fu.

## Summary

Introduces a recurrent structure-guided attention mechanism that progressively refines multi-person pose predictions by exploiting body structure priors.
