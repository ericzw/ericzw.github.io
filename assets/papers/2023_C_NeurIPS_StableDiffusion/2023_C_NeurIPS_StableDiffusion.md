# Stable Diffusion is Unstable

**Venue:** NeurIPS 2023 | **Type:** Conference

**Authors:** Chengbin Du, Yanxi Li, Zhongwei Qiu, Chang Xu.

## Summary

Discovers that small perturbations to text prompts can cause Stable Diffusion to produce semantically distorted outputs, revealing a critical robustness vulnerability in text-to-image generation.
