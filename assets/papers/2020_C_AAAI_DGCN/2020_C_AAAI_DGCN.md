# DGCN: Dynamic Graph Convolutional Network for Efficient Multi-person Pose Estimation

**Venue:** AAAI 2020 | **Type:** Conference

**Authors:** Zhongwei Qiu, Kai Qiu, Jianlong Fu, Dongmei Fu.

## Summary

Proposes a dynamic graph convolutional network that adaptively constructs graph structures for efficient and accurate multi-person pose estimation.
